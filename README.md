# PKG Explorer

Interface gráfica para navegar pelo conteúdo de arquivos `.pkg` de PS4 como se fossem um
arquivo compactado (zip/tar.gz) e extrair apenas os arquivos ou pastas desejados.

> Em desenvolvimento.

## Créditos

- A lógica de leitura de PKG/PFS foi adaptada do [shadPS4](https://github.com/shadps4-emu/shadPS4)
  (GPL-2.0-or-later).
- Inspirado no ShadPs4Plus PKG Extractor.
